# 常见问题

## 为什么 AI 模式处理长视频很慢？

OpenCV 模式是 CPU 算法。程序已经限制为仅处理所选时间范围，并且只计算
水印周边区域，但长视频仍然需要逐帧处理。

## 为什么 ProPainter 比 AI 模式慢？

ProPainter 需要计算光流并执行时空 Transformer。6GB 笔记本显卡能处理的
内部分辨率有限，因此长视频会拆成多个短片段串行处理。

## 可以同时启动两个强力任务吗？

不建议。程序在单个实例内限制为一个 ProPainter 任务；多个应用实例会
分别争抢显存。

## 失败原因在哪里看？

队列任务的失败列会显示失败原因。若文本被截断，可以将鼠标悬停在文字上
查看完整内容。

## 安装包为什么这么大？

安装包内置 FFmpeg、OpenCV、CUDA PyTorch 和 ProPainter 权重，因此不需要
用户额外配置 Python 环境。
